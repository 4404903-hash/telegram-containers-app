# AutoBazar v4.0 — велике оновлення

## Додано
- Мапа 2000×2000 px.
- Камера тримає локального персонажа по центру екрана.
- Одна площадка на 100 місць у формі стадіону.
- VIP-місця №1–10 біля центрального офісу.
- Безкоштовні випадкові місця №11–100.
- Центральний офіс із продажем авто та зв'язком із розробником.
- Покрокова форма продажу: марка/модель → рік/ціна/колір → опис.
- Екран завантаження.
- Псевдо-3D CSS-машинки.
- Кристали та перевірка VIP-вартості.

## Перед публікацією
1. У `public/js/app.js` замініть `YOUR_DEVELOPER_USERNAME` на Telegram username розробника без `@`.
2. У DEMO_MODE новому користувачу нараховується 30 тестових кристалів.
3. У production кнопка купівлі кристалів показує заглушку. Для реальних платежів треба підключити Telegram Payments/Stars.
4. Поточний ZIP зберігає дані у `data/store.json`, як у вихідному архіві. Для Render без втрати даних необхідно підключити PostgreSQL-версію сервера.
