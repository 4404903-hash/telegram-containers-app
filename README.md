# AutoBazar 8.0

Telegram Mini App: 3D-автобазар на 100 місць, оголошення на 24 години та приватні чати покупців і продавців.

Повна інструкція українською: [INSTALL_UK.md](INSTALL_UK.md). Звіт про зміни: [AUDIT_UK.md](AUDIT_UK.md).

## Локальний запуск

Потрібен Node.js 22 або 24. Рекомендовано 24 LTS.

```bash
npm ci
cp .env.example .env
```

У `.env` встановіть `DEMO_MODE=true`, залиште `BOT_TOKEN` та `DATABASE_URL` порожніми.

```bash
npm test
npm start
```

Відкрийте http://localhost:3000. Демо-дані зберігаються в `data/demo`. Для другого тестового профілю відкрийте http://127.0.0.1:3000. Демо-режим призначений тільки для локальної перевірки.

## Telegram

Потрібні `DEMO_MODE=false`, `BOT_TOKEN`, HTTPS `APP_URL` і PostgreSQL `DATABASE_URL`. Сервер перевіряє підпис Telegram. Кнопка «Купити» відкриває діалог у грі. Сповіщення надходять через бота за дозволом користувача. Щоденний бонус — 5 кристалів, VIP — 10 кристалів на добу, звичайне місце безкоштовне.

## Структура

- `server.js`, `server/` — сервер, база, авторизація та сповіщення.
- `public/index.html`, `public/js/app.js`, `public/js/scene.js`, `public/css/style.css` — інтерфейс і 3D-сцена.
- `public/assets/models/` — готові GLB та координати місць.
- `blender/build_assets.py` — генератор Blender-моделей.
- `tests/` — тести сценаріїв і збереження даних.
- `scripts/setup-bot.js` — встановлення кнопки меню бота.

Моделі — оригінальні умовні седан, SUV і хетчбек у восьми кольорах. Графіка відтворює композицію зразка у стилізованому 3D. Точні заводські моделі автомобілів і реальні грошові платежі не реалізовані: угоду покупець і продавець обговорюють у чаті, як передбачено сценарієм.
