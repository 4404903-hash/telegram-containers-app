# AutoBazar 8.0 — встановлення через Git Bash

## Що в архівах

- `01-autobazar-game.zip` — весь проєкт із готовими GLB-моделями. Усередині папка `autobazar-v8`. Цього архіву достатньо для запуску гри.
- `02-autobazar-blender.zip` — редаговані Blender-файли, GLB, координати 100 місць і генератор моделей. Для зміни моделей; другий раз копіювати їх у гру не потрібно.
- `03-autobazar-git-patch.zip` — альтернативне оновлення через `git apply`, для початкового коміту `aea91f9f01b3eec0cde5ef6f97d9a21b23608b90`. Не застосовуйте патч після копіювання повного проєкту: це два різні способи одного оновлення.

У ZIP немає ваших токенів, `.env`, бази користувачів або `node_modules`. Ігровий архів містить моделі для браузера; важкі редаговані `.blend` винесені в другий архів.

## 1. Найпростіший спосіб перевірити гру на комп’ютері

Встановіть Node.js 24 LTS і Git for Windows з офіційних сайтів. Розпакуйте `01-autobazar-game.zip` у Downloads. Відкрийте Git Bash:

```bash
cd /c/Users/user/Downloads/autobazar-v8
npm ci
cp .env.example .env
notepad .env
```

Для локальної перевірки збережіть такий `.env`:

```dotenv
PORT=3000
DEMO_MODE=true
BOT_TOKEN=
DATABASE_URL=
DEVELOPER_USERNAME=s_5994
```

Далі:

```bash
npm test
npm start
```

Відкрийте `http://localhost:3000`. Вгорі є кнопка «Додати приклади»: вона додає до 30 чітко позначених тестових оголошень. У бойовому режимі цієї кнопки та маршруту немає. Після перевірки зупиніть сервер клавішами Ctrl+C.

Демо-база зберігається в `data/demo`. Не копіюйте її на бойовий сервер. Для другого тестового профілю відкрийте `http://127.0.0.1:3000` або окремий профіль браузера. Тестовий режим призначений тільки для власної локальної перевірки: ідентифікація в ньому спрощена.

## 2. Оновити ваш GitHub-репозиторій повними файлами

Нижче використовується нова копія репозиторію, щоб не змішувати оновлення з незбереженими змінами. Якщо ви вже працюєте в іншій копії — спочатку збережіть її зміни окремим комітом.

```bash
cd /c/Users/user/Documents
git clone https://github.com/4404903-hash/telegram-containers-app.git autobazar-update
cd autobazar-update
git switch -c autobazar-v8
git status --short
```

Якщо остання команда нічого не показує, скопіюйте розпаковану папку з архіву:

```bash
cp -a /c/Users/user/Downloads/autobazar-v8/. ./
```

Приберіть старі клієнтські модулі: новий `index.html` їх уже не завантажує.

```bash
git rm --ignore-unmatch public/js/camera.js public/js/chat.js public/js/controls.js public/js/core.js public/js/garage.js public/js/interactions.js public/js/marketplace.js public/js/player.js public/js/sell.js public/js/slot-3d-car.js public/js/socket.js public/js/three-market.js public/js/legacy/app-single-file.js
npm ci
npm test
git diff --stat
git add .
git commit -m "Complete AutoBazar marketplace, 100-slot Blender scene and private chat"
git push -u origin autobazar-v8
```

У GitHub відкрийте Pull Request з `autobazar-v8` до вашої основної гілки. Після перевірки об’єднайте його. Якщо хостинг автоматично розгортає основну гілку, після об’єднання почнеться оновлення. Не використовуйте `git push --force`.

## 3. Альтернатива: встановити через патч

Цей спосіб замінює крок 2. Розпакуйте `03-autobazar-git-patch.zip` у Downloads. Він містить усі зміни, включно з GLB, доданими файлами та видаленнями старих модулів.

```bash
cd /c/Users/user/Documents
git clone https://github.com/4404903-hash/telegram-containers-app.git autobazar-patch
cd autobazar-patch
git switch -c autobazar-v8 aea91f9f01b3eec0cde5ef6f97d9a21b23608b90
git apply --check /c/Users/user/Downloads/autobazar-v8.patch
git apply /c/Users/user/Downloads/autobazar-v8.patch
npm ci
npm test
git add .
git commit -m "Complete AutoBazar v8"
git push -u origin autobazar-v8
```

Якщо `git apply --check` повідомляє конфлікт, не запускайте наступний `git apply`. Базові файли відрізняються від перевіреного коміту; використайте нову копію саме цього коміту або перенесіть зміни вручну. Нові зміни вашої основної гілки потребують звичайного злиття через Pull Request.

## 4. Бойовий запуск у Telegram

Потрібні постійно запущений Node.js-сервер, PostgreSQL і HTTPS-домен. Статичний GitHub Pages не запускає цей сервер і приватні чати. Проєкт має запускатися одним екземпляром Node.js; горизонтальне масштабування потребує спільного Socket.IO-адаптера.

На вашому хостингу встановіть:

```dotenv
NODE_ENV=production
DEMO_MODE=false
BOT_TOKEN=ТОКЕН_ВАШОГО_БОТА
APP_URL=https://ВАШ-ДОМЕН
DATABASE_URL=postgresql://КОРИСТУВАЧ:ПАРОЛЬ@ХОСТ:5432/БАЗА
DATABASE_SSL=false
DEVELOPER_USERNAME=s_5994
```

`PORT` зазвичай задає хостинг. Якщо він не задає — використайте `3000`. Для зовнішнього PostgreSQL із TLS установіть `DATABASE_SSL=true`, якщо це вимагає ваш провайдер; перевірка сертифіката ввімкнена. Для приватного внутрішнього з’єднання без TLS залиште `false`. Не додавайте параметрів, які вимикають перевірку сертифікатів.

Команда встановлення: `npm ci --omit=dev`. Команда запуску: `npm start`. Адреса перевірки: `https://ВАШ-ДОМЕН/health`. Нормальна відповідь містить `"ok":true` та `"slots":100`.

Також є Dockerfile. Якщо користуєтеся Docker на сервері:

```bash
docker build -t autobazar:v8 .
docker run -d --name autobazar --restart unless-stopped --env-file .env -p 3000:3000 autobazar:v8
```

Перед контейнером потрібен налаштований HTTPS-проксі вашого хостингу. У Docker `.env` має містити бойові значення. Сам Dockerfile не створює базу, домен або TLS-сертифікат.

### Telegram-бот

1. У BotFather відкрийте вашого бота та налаштуйте Main Mini App із `https://ВАШ-ДОМЕН`.
2. Запишіть токен у змінні середовища сервера. Ніколи не вставляйте його в `public/`, HTML або GitHub.
3. Для кнопки меню бота запустіть у папці проєкту, де `.env` містить ваші `BOT_TOKEN` та `APP_URL`:

```bash
npm run setup:bot
```

4. Відкрийте бота в Telegram і запустіть гру його кнопкою. У бойовому режимі звичайний браузер без Telegram-авторизації не ввійде — це очікуваний захист.
5. У грі: ⚙ → «Увімкнути Telegram-сповіщення» → дозволити боту надсилати повідомлення. За потреби відкрийте діалог із ботом і натисніть Start.
6. Перевірте другим Telegram-акаунтом: виставте авто → відкрийте його → «Купити» → надішліть повідомлення. Продавець має отримати повідомлення від бота з кнопкою входу в гру.

Сам бот не читає особисті переписки користувачів. Приватний чат цього проєкту зберігається всередині гри. Бот надсилає сповіщення про ці ігрові повідомлення. «Купити» відкриває цей діалог і не списує гроші.

Черга сповіщень обробляється кожні 15 секунд. Тимчасові збої повторюються; за блокування бота запис позначається `failed`. Звук, банер та показ на заблокованому телефоні залежать від налаштувань Telegram, системи телефона, режиму «Не турбувати» та дозволу користувача. Програма не може примусово ввімкнути їх.

Офіційні довідки: https://core.telegram.org/bots/webapps та https://core.telegram.org/bots/api#sendmessage.

## 5. Що буде з вашою поточною базою

Перед першим бойовим запуском зробіть резервну копію PostgreSQL у панелі хостингу. За наявності `pg_dump` можна використати надійне з’єднання, налаштоване вашими `PGHOST`, `PGUSER`, `PGDATABASE` і способом автентифікації:

```bash
pg_dump --format=custom --file=autobazar-before-v8.dump
```

Не викладайте резервну копію бази в GitHub. Сервер додає відсутні поля та індекси автоматично; наявні таблиці користувачів і повідомлень не видаляються. Старі оголошення отримують `expires_at = created_at + 24 години`. Тому оголошення старше доби одразу стають неактивними. Некоректні або повторні старі номери місць знімаються з активної площадки зі збереженням записів. Це описано в `AUDIT_UK.md`.

## 6. Blender-моделі

Відкривайте `.blend` у Blender 4.5 LTS або новішому. `market.blend` містить площадку з окремими об’єктами, `car-colors.blend` — 24 комбінації (3 кузови × 8 кольорів). Окремі файли: `sedan.blend`, `suv.blend`, `hatchback.blend`, `office.blend`, `fence-and-gates.blend`, `trees.blend`, `street-lamps.blend`.

Кузови — авторські умовні моделі, без логотипів брендів. Напис «BMW X5» в оголошенні не означає точну заводську 3D-модель X5. Основні GLB: `market.glb`, `sedan.glb`, `suv.glb`, `hatchback.glb`. Гра змінює колір матеріалу `BodyPaint` відповідно до оголошення.

Головна композиція: місця 1–10 з боків офісу, 11–20 та 21–30 перед ним. Місця 31–100 розташовані далі за офісом. Кнопка → біля назви площадки переходить між ділянками. Джойстик, перетягування, WASD і стрілки рухають камеру; +/− змінюють масштаб; ⌂ повертає до входу.

Для повної повторної генерації в Git Bash змініть шлях до вашого Blender за потреби:

```bash
"/c/Program Files/Blender Foundation/Blender 4.5/blender.exe" --background --factory-startup --python blender/build_assets.py -- --output public/assets/models
```

Перегенерація замінює файли моделей. Спочатку збережіть ручні зміни під іншими назвами. Якщо міняєте місця вручну, синхронізуйте `public/assets/models/slots.json`: гра використовує ті самі координати, що й Blender-генератор. Під час самостійного експорту використовуйте glTF Binary `.glb`, +Y Up, без камер і світла. Зберігайте імена матеріалів; зміна `BodyPaint` порушить автоматичне фарбування.

## 7. Що перевірено та що перевірити у вас

Перевірено автоматичними тестами серверні сценарії та ручним проходженням у браузері створення авто, картку, приватний діалог двох тестових профілів і відповідь. Є перевірка мобільного розміру 390×844. Інтеграційні тести використовують PostgreSQL-двигун PGlite, а Telegram API — імітацію відповідей; бойовий хостинг і реальні телефони не були підключені.

Після розгортання обов’язково пройдіть крок 4 двома реальними Telegram-акаунтами. Перезапустіть сервер та перевірте збереження авто й чатів. Токен і доступ до вашого хостингу в цьому завданні не надавалися, тому сам бойовий запуск не виконувався.
